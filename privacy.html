Privacy Policy

Last updated: October 29, 2026

SAMS Automation is a private tool for St. Augustine's Parish. It runs on one parish computer and signs in to a single Google account. This policy explains what it accesses and why.

Google data it accesses

  • Gmail (read, send, labels): it reads only messages whose subject starts with SAMS- and the replies to its own messages. It sends summary and confirmation emails to the parish schedule coordinator, and marks handled messages as read with a label.
  • Google Sheets (read and edit): it reads the parish ministry schedule spreadsheet and edits only the cells of a change the coordinator has confirmed.
  • Google Drive (file names only): it looks up the schedule spreadsheet by name. It does not open or download other files.

How the data is used

  • The text and attachments of schedule-change emails are sent to two AI services, Google Gemini and Anthropic Claude, only to read the requested changes. Nothing else from the mailbox is sent.
  • Copies of those emails, the AI readings, logs and a spreadsheet backup taken before each edit are kept on the parish computer so changes can be checked.
  • Data is used only to run the parish ministry schedule. It is not sold, not used for advertising, and not shared with anyone else.

Google API Services User Data Policy

SAMS Automation's use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

The account owner can remove SAMS Automation's access at any time at myaccount.google.com/permissions. Local copies can be deleted from the parish computer on request.
